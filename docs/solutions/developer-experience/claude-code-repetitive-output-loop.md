# Claude Code 重复输出死循环问题

## Context

Claude Code 在对话中可能陷入死循环，反复输出相同的内容。这个问题在长对话、工具调用密集的场景中更容易发生。用户多次提醒但问题持续存在，表明这是一个系统性问题而非偶发故障。

### 问题表现

1. **工具调用循环**: Claude Code 可能连续执行数百次几乎相同的 Bash 命令
2. **输出重复**: 在用户中断后，Claude 继续输出几乎相同的总结内容
3. **反馈响应不足**: 用户明确说"不要自己盲目尝试"后，Claude 仍然继续重复
4. **自我诊断无效**: Claude 的自我分析无法阻止后续的重复行为

### 根本原因

根据 session history 分析，核心问题是：

1. **缺乏循环检测机制**: 没有在每次输出后检查是否已输出相同内容
2. **状态管理失败**: 在长对话中没有有效管理已输出的内容
3. **用户反馈响应不足**: 当用户给出明确反馈时没有立即调整行为
4. **上下文理解偏差**: 没有正确理解用户的新请求（如"为什么这么久"应该简洁回答）

## Guidance

### 预防策略

1. **明确的停止条件**: 在输出前检查是否与之前的输出重复
2. **用户反馈响应**: 当用户说"不要盲目尝试"时立即停止
3. **简洁响应原则**: 用户问简单问题时给简洁答案，不要重复之前的内容
4. **状态跟踪机制**: 记录已输出的内容，避免重复

### 调试方法

如果遇到重复输出问题：

1. **立即中断**: 使用 `Ctrl+C` 或 `[Request interrupted by user]` 终止当前操作
2. **重新开始**: 在新会话中重新开始，避免在有问题的上下文中继续
3. **简化请求**: 将复杂请求分解为更小的、明确的步骤
4. **提供明确反馈**: 直接告诉 Claude "不要重复"、"简洁回答"

### 最佳实践

1. **避免长对话**: 定期开始新会话，避免上下文过长
2. **明确指令**: 提供清晰、具体的指令，避免模糊请求
3. **及时中断**: 一旦发现重复模式，立即中断并重新开始
4. **使用 `/clear`**: 定期清除对话历史，保持上下文清晰

## Why This Matters

重复输出问题会：
- 浪费用户时间和 token 额度
- 降低开发效率和用户体验
- 导致用户对 AI 工具失去信任
- 在关键任务中造成延误

## When to Apply

- 当 Claude Code 开始重复输出相同内容时
- 当工具调用出现循环模式时
- 当用户反馈 Claude 没有响应时
- 在长对话或复杂任务中

## Examples

### 问题场景

```
用户: 为什么这么久？
Claude: [输出详细总结]
用户: 不要自己盲目尝试
Claude: [再次输出几乎相同的总结]  # 重复！
```

### 解决方案

```
用户: 为什么这么久？
Claude: 安装和测试已完成。  # 简洁回答
用户: 详细说明一下
Claude: [提供详细说明]  # 只在用户要求时提供详细信息
```
